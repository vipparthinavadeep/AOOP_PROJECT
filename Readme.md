# Smart Recommendation System

A Java-based application developed as part of the **Advanced Object-Oriented Programming (AOOP)** course. The system aims to provide personalized recommendations based on users' interests, preferences, ratings, and previous interactions.

## 📌 Project Overview

The Smart Recommendation System helps users discover relevant products or items without manually searching through large collections.

The application analyzes user preferences and ratings to generate personalized suggestions using content-based filtering and popularity-based ranking techniques.

The project focuses on implementing real-world software functionality while demonstrating various Advanced Object-Oriented Programming concepts in Java.

## 🎯 Objectives

- Develop a personalized recommendation application using Java.
- Implement user registration and login functionality.
- Allow users to browse products and explore categories.
- Manage user preferences, ratings, and favourites.
- Generate recommendations based on user interests.
- Apply Advanced Object-Oriented Programming concepts.
- Develop a modular, reusable, and maintainable application.

## 🏗️ Project Modules

The application will be organized into the following modules:

1. **User Management** – Registration, login, and profile management.
2. **Product Management** – Managing products and categories.
3. **Preference Management** – Recording user interests and preferences.
4. **Rating and Favourites** – Managing product ratings and saved items.
5. **Recommendation Engine** – Generating personalized recommendations.
6. **Application Integration** – Connecting all modules into one application.

## 🎯 Expected Outcome
